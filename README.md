# Mini E-Commerce Backend

## My First Backend Project

This is my first backend project, built to learn how modern web applications handle authentication, databases, APIs,
file uploads, and server-side logic. The project is a simple e-commerce backend that provides APIs for managing users, products, and carts.

## What I Learned

### Backend Development
- Building REST APIs using Express.js
- Organizing routes, controllers, and middleware
- Handling HTTP requests and responses

### Database Management
- Working with MongoDB and Mongoose
- Creating schemas and models
- Performing CRUD operations
- Understanding relationships between collections

### Authentication & Security
- Implementing JWT-based authentication
- Password hashing with bcrypt
- Protecting private routes
- Managing user sessions securely

### File Handling
- Uploading images using Multer
- Storing images on Cloudinary
- Managing file data in the database


## Conclusion

Building this project taught me the fundamentals of backend development and gave me hands-on experience with technologies 
used in production applications. Along the way, I faced and solved many challenges, which helped me improve my debugging skills 
and understanding of how backend systems work. This project serves as the foundation for more advanced projects that I plan to build in the future.
